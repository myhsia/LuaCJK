## [LuaCJK-v0.0.1](https://github.com/myhsia/LuaCJK/releases/tag/LuaCJK-v0.0.1)

- Provide the CJK font family interface (`\setCJKmainfont`, `\setCJKsansfont`, `\setCJKmonofont`, `\setCJKfamilyfont`, `\CJKfamily`, `\newCJKfontfamily`, `\CJKfontspec`); an undeclared family warns once instead of at every use.
- Add `LuaCJK-listings`, which keeps CJK characters in place inside a `listings` block, counts each of them as two columns, and turns the spacing adjustments off; LuaCJK loads it automatically with `listings`.
- Ship `ctex-engine-luacjk.def` as the LuaTeX backend for `ctex`, selected with the option `engine = luacjk`. The name differs from the file that `ctex` installs, so both packages can be installed side by side.
- Refuse `CJKfntef` in the `ctex` engine file, as `ctex`'s own LuaTeX backend does; the message points at `LuaCJKfntef`.
- Refuse to load with `luatexja`, which adjusts the same nodes; `\LuaCJKversion` prints the version of the package.
- Provide the `PunctStyle` key with the `quanjiao`, `plain`, `banjiao`, `kaiming`, `CCT`, and `hangmobanjiao` styles. Under a style with a fixed width the advance of an opening or middle mark moves its ink as well, and a dash or an ellipsis keeps its advance, so a run of long punctuation is not collapsed.
- Provide `\LuaCJKEditPunctStyle` to edit the punctuation sets of the current style, and `AllowBreakBetweenPuncts`.
- Provide `\LuaCJKsetwidth` and `\LuaCJKsetkern` for per-mark widths and per-pair gaps that override the selected punctuation style.
- Provide `\LuaCJKDeclareSubCJKBlock` with `\LuaCJKCancelSubCJKBlock` and `\LuaCJKRestoreSubCJKBlock`, so a range of characters can use its own font inside a family.
- Provide `\LuaCJKDeclareCharClass`, `\LuaCJKDeclarePunctClass`, and `\LuaCJKResetCharClass` to override the class of a code-point range. The classes carry the names of `xeCJK` (`FullLeft`, `FullRight`, `HalfLeft`, `HalfRight`, `NormalSpace`, `CJStarter`, `CM`, `Boundary`), the reset also restores the normal-spaced set, and the built-in table covers the CJK blocks of Unicode 15 and 16.
- Provide `\LuaCJKDeclarePunctStyle` for a punctuation style of your own, with the keys `compress-adjacent`, `adjacent-ratio`, and `keep-open-close`.
- Provide `AutoFakeBold`, `AutoFakeSlant`, `EmboldenFactor`, and `SlantFactor`; a family that sets `BoldFont` or `ItalicFont` keeps its real faces.
- Provide `\LuaCJKsetup`, and accept the same keys as package options, for example `\usepackage[PunctStyle = banjiao]{LuaCJK}`; an unknown key warns instead of raising an error.
- Every setting travels with the characters: a snapshot of the options is recorded on the glyphs, so a group that ends before the paragraph does still decides how its own text is set. This covers `CJKglue`, `CJKecglue`, `PunctStyle`, `PunctKinsoku`, `LatinPunct`, `CJKmath`, `PunctWidth`, `PunctBoundWidth`, `CheckSingle`, `WidowPenalty`, `AllowBreakBetweenPuncts`, `AutoFallBack`, and the cancelled sub-blocks.
- Provide `\LuaCJKdisable` and `\LuaCJKenable` to suspend the typographic adjustments while keeping CJK font selection.
- Provide `\LuaCJKShipoutHook`, which runs code through the standard `shipout/before` hook.
- Provide `\LuaCJKnobreak` and the `PunctWidth` option; the prohibition survives `PunctKinsoku` being off, as does that of `\LuaCJKVerbAddon`, because the switch only controls the punctuation rules.
- Provide `\LuaCJKVerbAddon` and `\LuaCJKOffVerbAddon`, which make one CJK character as wide as two spaces of the current monospaced font and forbid breaks between CJK characters, so columns in code listings stay aligned.
- Add the `Verb` option (`true`, `env`, `env+`, `false`) to control what happens inside `\verb` and the verbatim-like environments.
- Suspend the adjustments automatically in `\verb`, `verbatim`, `fancyvrb`, and `listings`; `\LuaCJKdisable` records its state per node.
- Provide `PunctFamily`, which sets a separate CJK family for the punctuation marks.
- Provide `\defaultCJKfontfeatures` and `\addCJKfontfeatures`.
- Provide `\setCJKfallbackfamilyfont` and `AutoFallBack` for characters that the selected CJK font does not have.
- Provide `\songti`, `\heiti`, `\fangsong`, `\kaishu`, `\lishu`, and `\youyuan` as shorthands for the families `zhsong`, `zhhei`, `zhfs`, `zhkai`, `zhli`, and `zhyou`.
- Provide `\normalspacedchars` so that slashes, backslashes, and hyphens take no glue on either side.
- Ignore the zero-width format characters (U+200B, U+200C, U+200D, U+2060, U+180E) and the variation selectors at the input, so that they neither take glue nor separate two CJK characters.
- Add the `LocalConfig` option, which reads `luacjk.cfg` or `luacjk-<name>.cfg` at the end of the package.
- Add the `LoadFandol` option, which supplies Fandol fonts when the document declares none.
- Provide `CJLineBreak`, which reads the `Line_Break` property `CJ` from `LineBreak.txt` and forbids a line break before those characters.
- Provide `KaiMingPunct`, `MiddlePunct`, `LongPunct`, and `NoBreakLongPunct`, each with `+` and `-` forms, to edit the punctuation character sets.
- Drop the placeholder glyph that a font without the character leaves behind (one `.notdef` glyph in some fonts, a private-use glyph in others).
- Provide `LatinPunct`, which keeps the shared quotation marks, the middle dot, and the ellipses in the Latin font instead of the CJK font.
- Inserted glue, kerns, and penalties inherit the attributes of the neighbouring node, so an attribute-based decoration such as `\CJKunderdot` stays in one piece across CJK/CJK and CJK/Latin boundaries.
- Provide CJK/CJK and CJK/Latin spacing with `CJKglue`, `CJKecglue`, `CJKspace`, and `xCJKecglue`. The default glues are recomputed at every font selection, so they follow `\small`, `\Large`, and `\zihao`, and a value keeps its stretch and shrink orders. No glue is inserted between two long punctuation marks, so a run of dashes or ellipses stays one unit.
- Provide `PunctKinsoku` line-breaking prohibitions: closing punctuation cannot start a line, opening punctuation cannot end a line, and long punctuation runs are kept together.
- Provide `CJKmath` and `\setCJKmathfont` for CJK characters in math mode, including nested math lists such as fractions. The family is registered as a math family, so a character in a script or a fraction keeps the size of that math style; with `CJKmath` off, a CJK character in math mode warns once.
- Provide `PunctBoundWidth`, which leaves only the given advance inside the line and hangs the rest of the mark into the margin: at the end of a line, at its start, and when the mark ends a box such as `\mbox`. Only the lines of the paragraph itself are shifted.
- Provide `CheckSingle` and `WidowPenalty`, which stop a single CJK character from ending up alone on the last line of a paragraph.
- Add `LuaCJKfntef`, a `lua-ul` based companion package providing `\CJKunderline`, `\CJKunderdot`, and `\CJKsout`. `\CJKunderline` takes `thickness`, `depth`, `textformat`, `format` for the color of the rule, and any other key of `lua-ul`; the geometry defaults to `depth=0.2em` and `thickness=0.4pt`, and `top` and `bottom` override the computed values. Every decoration accepts `selectable`, `false` by default: a decoration symbol is then wrapped in an `ActualText` sequence that readers drop from the text they copy or select. Every decoration also accepts `subtract` (inset at both ends) and `skip` (leave out the punctuation); the decoration boxes of `lua-ul` are adjusted in place, with a matching kern and negative glue keeping the text where it was.
- Every decoration takes the same key set: `color`, `gap`, `height`, `symbol`, `sep`, `textformat`, and `hidden`, which keeps the dimensions of the text and draws no glyph. A bare color name is accepted, so `[red]` and `[subtract]` both work, and a key that a command does not use is ignored. `\CJKsout` strikes at `height=0.3em`, through the middle of a CJK glyph, and `height=0.5ex` restores the Latin position.
- Add `\CJKunderdblline`, `\CJKunderwave`, and `\CJKxout`; the wave and the slash are drawn with `l3draw` and repeated with leaders, so they stay in phase along a line. Their patterns are built at use time and scale with the font size, the box that holds them has zero height and depth, so a decoration never opens up its line, and a rule-based decoration fills its span exactly.
- Provide `\LuaCJKemdescent`, the depth of the em box of the current font, so that an object of height `1em` placed at that depth covers the one-em square of a CJK character in any font.
- Add `\CJKunderanyline` and `\CJKunderanysymbol` for arbitrary rules and repeated symbols; the underline type is cached by the arguments, and `\CJKunderanysymbol` puts one symbol per em, centered in the cell, its depth measured from the baseline to the top of the symbol.
- Add the `CJKfilltwosides` environment, which justifies every line to a given width (the CJK glue is given infinite stretch inside the box) and places the box on the baseline as requested. It is tagged: a text block in vertical mode, part of the surrounding paragraph in horizontal mode.

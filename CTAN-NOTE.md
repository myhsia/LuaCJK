The package ships three Lua modules in tex/luatex/luacjk/ and a ctex engine
file, so this upload carries a TDS-ready archive beside the package directory.
It is there to make installation and the TeX Live import straightforward; if
the unpacked tree is all you need, please drop the .tds.zip without
hesitation. LuaCJK is meant to run in parallel with xeCJK and is selected by
ctex's engine = luacjk option.
